# 💣 지뢰찾기

> 브라우저에서 즐기는 클래식 지뢰찾기입니다. PRD에 요구사항을 정리하고 구현 계획을 확인한 뒤, HTML·CSS·JavaScript로 만들었습니다. 실습 흐름은 [guide.md](./guide.md)를 참고하세요.

## 게임 소개

숫자 단서를 이용해 지뢰가 없는 칸을 모두 여세요. 칸을 열려면 마우스 왼쪽 버튼, 지뢰가 있다고 예상하는 칸에 깃발을 표시하거나 해제하려면 오른쪽 버튼을 사용합니다. 빈 칸을 열면 주변의 빈 칸도 자동으로 열립니다.

| 난이도 | 격자 | 칸 수 | 지뢰 |
|---|---:|---:|---:|
| 초급 | 9행 × 9열 | 81 | 10개 |
| 중급 | 16행 × 16열 | 256 | 40개 |
| 고급 | 16행 × 20열 | 320 | 60개 |

첫 칸과 그 주변 칸에는 지뢰가 놓이지 않습니다. 지뢰 배치는 첫 칸을 연 뒤 시작합니다. 지뢰가 없는 칸을 모두 열면 승리하고, 지뢰를 열면 패배합니다.

## 어떻게 만들었나요

먼저 [PRD.md](./PRD.md)에 게임 규칙과 화면 요소를 정리했습니다. 그 내용을 바탕으로 구현 계획을 확인한 다음 기능을 구현했습니다. 화면 구조는 `index.html`, 디자인은 `style.css`, 게임 동작은 `script.js`로 나눴습니다.

요구사항에 맞춘 기본 초급 모드에 타이머, 남은 지뢰 수, 재시작 기능을 구현했습니다. 이후 요청에 따라 난이도 선택을 추가하고, 중급과 고급의 격자 크기 및 지뢰 수도 조정했습니다.

## freeform 버전과 비교했을 때

freeform 방식은 PRD 없이 여러 줄의 요청으로 바로 구현하고, 이 버전은 요구사항을 먼저 문서화한 뒤 계획을 확인하고 구현하는 흐름입니다. 따라서 이 버전에서는 첫 클릭 안전 규칙이나 승리 조건처럼 세부 규칙을 구현 전에 명시적으로 확인할 수 있었습니다.

현재 작업본에는 freeform 버전의 결과물이나 두 버전을 직접 실행해 비교한 기록이 없습니다. 그래서 구체적인 기능 차이나 어느 버전을 최종 선택했는지는 단정하지 않습니다. 이 README는 확인 가능한 PRD 기반 구현을 소개합니다.

## 실행 방법

저장소에서 `index.html`을 브라우저로 열면 됩니다. 별도의 빌드나 패키지 설치는 필요하지 않습니다. GitHub Pages에 배포할 때는 `index.html`, `style.css`, `script.js`를 같은 경로에 둡니다.

## 커스터마이징한 부분

- 초급·중급·고급 난이도 선택을 추가했습니다. 넓은 격자는 작은 화면에서 가로로 스크롤할 수 있습니다.
- 첫 칸을 여는 순간 타이머를 시작하고, 승리나 패배 시 멈춥니다.
- 남은 지뢰 수는 선택한 난이도의 지뢰 개수에서 설치한 깃발 수를 뺀 값으로 표시합니다.
- 지뢰찾기 격자와 상태 표시를 반응형 화면에 맞게 구성했습니다.
- 사용자 기록 저장 기능은 구현하지 않았습니다.
