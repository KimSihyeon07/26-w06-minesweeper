# 💣 FIELD STUDY / 09 : 지뢰찾기 (Minesweeper)

> 브라우저에서 즐기는 클래식 지뢰찾기 게임입니다. PRD(제품 요구사항 문서)에 요구사항을 명확히 정의하고, 체계적인 구현 계획을 거쳐 HTML5, CSS3, Vanilla JavaScript로 제작되었습니다.

---

## 🎯 게임 소개

숫자 단서를 이용해 지뢰가 없는 칸을 모두 찾아내는 퍼즐 게임입니다.

- **좌클릭**: 칸 열기 (빈 칸일 경우 주변 안전 구역 자동 확장)
- **우클릭**: 깃발(⚑) / 물음표(?) / 표시 해제 순환 토글
- **첫 클릭 안전 보장**: 첫 번째로 클릭한 칸과 주변 8방향에는 절대 지뢰가 생성되지 않습니다.

### 📊 난이도 체계
| 난이도 | 격자 크기 | 총 칸 수 | 지뢰 개수 |
| :--- | :---: | :---: | :---: |
| **초급 (BEGINNER)** | 9행 × 9열 | 81개 | 10개 |
| **중급 (INTERMEDIATE)** | 16행 × 16열 | 256개 | 40개 |
| **고급 (ADVANCED)** | 16행 × 20열 | 320개 | 60개 |

---

## 🛠️ 어떻게 만들었나요?

1. **문서화 기반 개발**: 코딩에 앞서 `PRD.md`에 게임 규칙과 UI 요소를 구체적으로 정의하여 요구사항의 누락을 방지했습니다.
2. **모듈화된 구조**: 
   - `index.html`: 접근성(ARIA)을 고려한 시멘틱 마크업 및 레이아웃 구조
   - `style.css`: CSS Grid 기반의 반응형 디자인 및 섬세한 타일 입체감 구현
   - `script.js`: BFS 알고리즘을 활용한 빈칸 연쇄 확장 및 난이도별 동적 제어 로직

---

## ✨ 주요 커스터마이징 및 기능

- **난이도 및 동적 UI**: 초·중·고급 난이도 선택 즉시 반응형 그리드와 계측기(남은 지뢰 수, 타이머)가 연동됩니다.
- **실시간 타이머 & 계측기**: 첫 칸을 여는 순간 타이머가 시작되며, 승리 또는 패배 시 자동으로 정지합니다.
- **우클릭 상태 순환**: 깃발과 물음표를 오가는 마우스 인터랙션을 지원하며, 게임 종료 시 상태가 안전하게 보호됩니다.
- **로컬 스토리지 기록 저장**: 난이도별 최고 기록(상위 5위)을 브라우저에 저장하여 도전 의욕을 높입니다.
- **오디오 효과**: Web Audio API를 활용한 효과음 및 배경음악 설정 기능 지원

## 🚀 실행 방법 및 배포

별도의 빌드나 복잡한 패키지 설치 없이, 저장소의 `index.html` 파일을 브라우저로 열어 바로 플레이할 수 있습니다. 

GitHub Pages를 통해 배포할 경우 `index.html`, `style.css`, `script.js` 파일을 동일한 경로에 업로드한 뒤 배포 브랜치(`gh-pages`)를 지정하면 곧바로 웹에서 즐기실 수 있습니다.
